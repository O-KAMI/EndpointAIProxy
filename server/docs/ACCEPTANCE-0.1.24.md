## 使用边界

源码保留 schema version 2 和既有凭据；普通升级不运行 init-db/migrate-db，不重建数据库。先部署 0.1.24、验证外部模型网关，再开启客户端 DSH。客户端 Go 版本与服务端版本独立。

管理页面的默认 HTTP 边界沿用现有部署；客户端 AES-GCM 不保护浏览器管理员链路。日志轮转模板未安装到生产；现场网络、账户、权限、轮转、IOA 与外部网关仍待现场确认。
