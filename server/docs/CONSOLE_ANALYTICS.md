# 0.1.23 控制台统计口径

默认进入数据分析，另有策略管理（白名单、连接网关）与资产管理。统计主要单位是终端，不采集请求正文、逐请求历史或趋势数据。

- 默认在线范围，阈值为心跳间隔两倍加 30 秒；陈旧阈值为五倍加 30 秒。离线范围只表示最后上报状态。
- Agent 运行覆盖只取 `running=true` 实例，同一终端同一类去重；CC Switch 单独展示，疑似 Agent 不计入。
- LLM 当前目标服务分布只统计 `isCurrent=true` 的当前启用配置，未产生请求也计入。公共域名按受控域名映射显示厂商；当前策略精确命中的 Base URL 显示“白名单目标 · 域名”；其他地址显示“自定义目标 · 域名”。回环地址显示为目标识别异常。
- 当前代理请求异常只统计当前启用、路由为 `attached`、未白名单绕过、本次客户端运行请求数大于零且最近结果失败的配置。后续成功、转白名单、停用或替换配置后不再计入。
- 客户端本次运行曾异常按 `failureCountSinceBoot > 0` 判断。服务端保留的上次运行结果只在明细中标为“上次运行结果”，不计入当前异常。
- 连接失败、路由失败和网关返回错误独立分组，同一终端可进入多组；网关返回错误不直接归因于本地代理。
- 白名单覆盖使用当前配置、`allowlistBypassed=true`、`routeStatus=bypassed` 和非空原始地址。同一规则按终端去重，总命中终端跨规则再次去重。它表示已配置直连，不代表已观测到实际直连请求。
- 停用、挂载失败和不支持接管另列为其他未接入代理状态；旧客户端及目标识别异常提示数据不足。

管理员只读接口为 `GET /admin/v1/analytics` 和 `GET /admin/v1/analytics/devices`，沿用管理员 Bearer 鉴权。公共参数为 `scope`（`online/all/stale/offline/legacyClient`）和 `os`。下钻支持 `kind`、`key`、`search`、`agent`、`provider`、`anomaly`（`latest/ever/none`）、`allowlist`、`skip`、`take`。`providerMode` 已移除，传入时返回 400。

聚合与下钻共用同一 MySQL 一致性只读快照和统计逻辑。页面每 60 秒刷新，恢复前台时立即刷新，并保留筛选和展开状态。
