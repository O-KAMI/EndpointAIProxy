## 已实现的主要改动

- 同步错峰、失败随机退避、按已接受版本拉取策略及低频完整核对；能力协商后
  使用轻量心跳，资产按变化上报并定期完整校准。旧服务仍使用原协议路径。
- 控制端有界数据库连接池、减少鉴权写入、防重放独立提交及后台过期清理；
  正常请求日志聚合与抽样，客户端和管理接口可选分离进程及连接预算。
- 注册覆盖保护、受控设备凭据恢复与审计；可选本地管理员账号、角色和 HTTPS
  会话；全局策略变更审计。公钥策略及命令验签为可选候选，尚未完成实际迁移。
- 设备列表数据库分页、部分筛选索引、可选统计和复杂筛选快照；统一策略校准
  状态。v2 回退 v1 时保留旧资产，但不把旧 v2 资产与校准结果视为当前状态。
- 命令批次及 v2 策略批次支持目标快照、限速、暂停、失败明细和审计；执行结果
  未知的命令需要人工核验。策略批次显示下发与校准为不同状态。
- 客户端转发并发和超时限制、磁盘低水位与进程内捕获预算、有限持久事件队列；
  断网时继续使用有效缓存。捕获降级及队列满仍可能造成证据缺失，必须监控。
