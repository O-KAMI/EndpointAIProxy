# 0.2.22 接管与控制流程实施结果

更新日期：2026-11-09。本记录是本轮现役答案；0.2.21 回传材料与冻结包保留历史，不能代替新候选。
Windows 最终候选为 **0.2.22 r2**，不签名，未在构建机安装。r1 中间包不交付使用。

## 已实现

- 异常保持配置并上报，不自动直连、不自动结束 DSH。沿用签名 `disableProxy` / `enableProxy`，
  先持久化停用，再在统一配置锁内恢复；周期校准、重启、策略更新不会解除停用。
  DSH 恢复有变更时回执为 `PROXY_DISABLED_RELOAD_REQUIRED`，控制台显示待应用重启。
- Desktop 账户路径处理后继续处理同一 profile 的显式 API-key/custom provider；产品版本字符串
  不再单独阻断。Desktop 账户校验受审查的插件实现，profile SDK 分开解析，未知契约仍拒绝。
- 新增可选 `verificationState`、`verificationReasonCode`、`reloadRequired`、
  `lastInferenceObservedAtUtc`、`observedPolicyVersion`。当前路由、当前策略下成功的实际推理
  POST 才形成观测；模型列表/健康检查不计，配置变更和旧在途请求不能证明新配置生效。
  旧心跳不输出新增默认值，保留旧 .NET 精确往返序列化兼容。
- 本地临时管理接口仅允许 Development 且带隔离 profile 标记；生产恢复走控制端命令。
- Windows/Mac 包内默认入口及控制端初始模板统一为
  `http://network-dlp-aigw.sf-express.com:80`，显式允许 HTTP，有效策略缓存仍优先。
- Windows/Mac 上报短账号；解析失败不使用 SID 充当账号。后端移除域/机器前缀，保留
  Administrator、Guest 等交互账号；旧查询、派生索引、快照及精确查询统一归一化。
  UI 使用“用户账号”，保留 `employeeIds` / `employeeExact` 兼容名称，不改数据库 schema。
- 策略错误保留错误码，补安全字段路径、合法枚举与 traceId；全局和设备覆盖均不回显
  URL 解析器携带的提交值。白名单与分流数组为整体替换，枚举为 `passthroughOriginal`。
- 原生观察补全捕获正文、压缩/partial、日志、SQLite/WAL、配置备份、诊断与磁盘空间。
  每分钟按两秒预算继续扫描，不完整/不可读为 null/未知；扫描不进入转发路径。
  Mac 提供 Python 只读目录工具，Windows 采样补线程、句柄并覆盖观察结束时刻。

## 阻断及待验

1. **DSH 官方 API-key 默认目录契约阻断**：rc.3 的动态模型目录要求官方 origin，回环改写会
   关闭动态列表。实际官方编译模块探针确认官方有 listing、回环无 listing。空补丁不再被当成
   “无配置”，报告 `DSH_DEFAULT_PROVIDER_UNVERIFIED`；显式官方 API-key 入口保守拒绝，报告
   `DSH_DYNAMIC_MODEL_CATALOG_UNSUPPORTED`。仅有 `models` 字段不构成目录独立证明。
   需要上游支持目录与推理入口独立或另行验证的集成契约；不修改整个用户配置来绕过。
2. 最终包独立 Win10/11、Mac 两架构、干净首装、旧 .NET 升级、IOA、多用户、真实 DSH
   Desktop/headless 推理与 SSE、配置恢复和新版原生/合成八小时报告仍待用户团队执行。
3. 十万在线混合负载、共享数据库断连、磁盘耗尽不进入在用灰度业务窗口；容量与高可用未验收。
4. 本机新增短时合成运行因现有服务占用 18080 在启动前停止，未停止或修改该服务。
   最终服务另行构建的摘要与 MSI 内服务一致；采样工具冒烟通过仍不替代合成八小时。
