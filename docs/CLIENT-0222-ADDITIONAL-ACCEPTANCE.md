# 0.2.22 接管与控制流程复测

本候选承接 0.2.21 r2，旧包及其报告保持原样。构建和合成测试不表示原生发行通过。
Windows 不签名；Mac 由交付团队分别构建、正式签名、公证并在两种架构上验收。

## 必须明确记录的边界

- DSH rc.3 默认 API-key provider 依赖官方域名启用动态模型目录。直接改为回环地址会改变行为，
  默认/空补丁 profile 暂报告 `DSH_DEFAULT_PROVIDER_UNVERIFIED`，不能标记接管通过。
  显式官方 API-key provider 也暂报告 `DSH_DYNAMIC_MODEL_CATALOG_UNSUPPORTED`；仅出现 `models`
  字段不能证明目录独立，不能据此绕过该门禁。自定义显式静态入口按支持契约处理。
- Desktop 账户 provider 验证受审查的插件实现，产品版本号变化本身不拒绝接管。
  未知实现、动态表达式及来源不明覆盖层仍拒绝；不是任意未来 DSH 版本都支持。
- 默认网关为 `http://network-dlp-aigw.sf-express.com:80`，有效缓存优先。
  真实网关联调使用 DeepSeek 凭据，覆盖三类协议和 SSE；不证明其他模型供应商凭据可用。
- 只有当前策略/路由下成功的实际推理 POST 才形成“已观察”状态；模型列表、健康检查不计。
  无推理活动是“尚未验证”，不能据此判定旁路；应用重启由测试人员操作。

## 针对性用例

| 用例 | 执行与通过条件 |
|---|---|
| 异常保持 | 在授权独立终端制造可恢复的上游错误；配置摘要不变、错误可见，不自动恢复原厂或结束 DSH |
| 远程停用 | 控制台下发 `disableProxy`；核对命令 ID、执行/回执时间、配置恢复日志和原始配置摘要 |
| 停用持久化 | 停用后等待至少三次校准，重启服务、更新策略、重复同一命令，均不得重新接管 |
| 重载提示 | DSH 配置已恢复但进程未重载，回执为 `PROXY_DISABLED_RELOAD_REQUIRED`，界面提示待应用重启 |
| 恢复冲突 | 停用前人为修改受测配置的受管理字段，确认保留用户修改并报告冲突；不清库或重注册 |
| 重新启用 | `enableProxy` 后配置接管；必要时手动重启应用，以同一轮真实请求关联证明生效 |
| 多 profile | Desktop/headless/自建 profile 与多版本并存；分别列 provider、协议、配置来源和实际观测结果 |
| 兼容契约 | 受支持静态结构不因产品版本字符串变化被拒；未知协议/动态覆盖层必须明确不支持 |
| 新网关 | 首次无缓存离线启动采用包内入口；已有有效缓存优先；三类协议逐请求出口及完整 SSE 可核对 |
| 账号 | 域前缀两种分隔符、本地短账号、同名不同 SID、Mac 短账号、解析失败；头/列表/精确搜索一致 |
| 策略错误 | 错误枚举/非法网关返回原错误码、非空 traceId、安全字段路径与允许枚举，不包含提交秘密 |
| 八小时 | 新包原生业务观察和独立合成观察各八小时，记录所有目录大小、磁盘、队列及进程资源 |

本地临时 attach/detach 管理接口只允许 Development 且有隔离 profile 标记的合成测试。
生产异常恢复使用控制台签名命令；离线维护与卸载先停服务。

## 回传结构

每个平台/架构一个受限 ZIP：`report.md`、`manifest.json`、`cases.csv`、`timing.csv`、
`resources.jsonl`、`evidence/`。报告至少包含：

1. 最终安装包 SHA-256、安装包内服务 SHA-256、版本、源码输入清单摘要、系统/架构与测试时间。
2. 每个用例 PASS/FAIL/BLOCKED、操作步骤、预期/实际、附件引用、失败码；未执行不能填 PASS。
3. 每轮业务关联：匿名终端标签、SID 别名、profile/provider/模型、请求 ID、协议、实际出口、
   HTTP 状态、完整 SSE 结束证据、当前策略版本。捕获索引与复制时间分别记录。
4. 控制事件分别记录发起、客户端执行结束、控制端回执可见；轮询发现时间单列。
5. 时间线全部使用 UTC；大小统一 bytes，图表换算 MiB=bytes/1048576。统计不完整填 null/未知。
6. 八小时首末资源、最大值、持续增长分析、业务轮次、重启/错误；磁盘变化不能只用摘要索引解释。

`manifest.json` 为每个附件列相对路径、字节数、SHA-256；不包含 ZIP 自身摘要。
回传前移除密码、API Key、生产客户端凭据、捕获正文和未经脱敏配置；以结构、摘要和请求 ID 取证。
任何真实业务旁路、配置恢复失败、持续资源增长均停止扩大试点。
